# Naph — HVAC Website (Demo)

Website for a residential and commercial heating, cooling and air quality company. Built with React, TanStack Start, Vite and Tailwind CSS.

## Local development

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Import this repository in Vercel.
2. Vercel reads `vercel.json` and builds with the Vercel preset automatically.
3. Optional: set `VITE_ESTIMATE_ENDPOINT` to a URL that receives the estimate form (JSON POST). Without it, the form runs in demo mode.
